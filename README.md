# Dunwoody Barber Shop

An accessible, mobile-friendly one-page website for Dunwoody Barber Shop and Kevin Lam, Master Barber & Owner.

## Business information

- 5064 Nandina Lane, Dunwoody, GA 30338
- (770) 396-8500
- Tuesday–Friday: 8:00 AM–6:00 PM
- Saturday: 8:00 AM–2:00 PM
- Sunday–Monday: Closed

## Site highlights

- Local-business SEO metadata and structured data
- Responsive desktop and mobile layouts
- Accessible navigation, headings, links, contrast, and focus states
- Click-to-call and directions actions
- Optimized portrait of Kevin and a custom social-sharing image

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

To verify a production build:

```bash
npm run build
```
